## 1. 처음 오신 분 · 문의 창구

- 공식 문의 창구는 **🦉｜부엉이-편지의 "Create ticket" 버튼**이다. 건의, 신고, 다이어리 신청, 기숙사 이전, 동아리 신청, 이벤트 이의, 버그 제보, 운영진에게 비밀스럽게 전할 말 모두 여기로 한다. 서버 이용 질문도 자유질문 포럼이 아니라 티켓으로 한다.
- 티켓은 **한 사람당 동시에 1개**만 열 수 있다. 새 티켓은 기존 티켓을 닫은 뒤 만든다. 같은 용건(예: 동아리원 추가)이 반복되면 기존 티켓을 이어서 쓰면 된다.
- 용건이 끝나면 회원이 직접 티켓을 닫아도 된다. **운영진 답변을 기다리는 중이면 닫지 말고 기다린다.**
- 운영진(학생회) 대부분이 직장인이라 **퇴근 후 처리하는 경우가 많고, 회의가 필요한 건은 최소 하루** 걸릴 수 있다.
- 가입 조건: 디스코드 **전화번호 인증**을 마친 계정만 이용할 수 있다 (스팸·가계정 차단 목적).
- 가입할 때 온보딩에서 **직군 역할 1개를 반드시** 고른다: 직장인 / 취준생 / 대학원생 / 대학생 / N수생 / 고등학생 / 중학생 / 독학법사(초등학생·홈스쿨링·검정고시생 등). `공부알림` 역할은 선택이다.

## 2. 기숙사

- 기숙사는 4개다: **소용돌이 🦋**(분홍), **노블레빗 🐇**(보라), **볼리베어 🐻‍❄️**(하늘), **펭도리야 🐧**(회색).
  - 소용돌이: 매일 조금씩 더한 노력, 성실함과 꾸준함
  - 노블레빗: 과정의 중요성, 책임감, 배려, 절제
  - 볼리베어: 어려운 환경에서도 굴하지 않는 꿈과 희망, 용기
  - 펭도리야: 조용한 지혜, 깊은 통찰, 내면의 성찰
- **기숙사를 배정받아야 서버 대부분의 채널이 열린다.** 배정 전(입학생)에는 서버규칙, 기숙사-배정, 부엉이-편지만 보인다.
- 배정 방법: **🪄｜기숙사-배정 채널의 "기숙사 배정 받기" 버튼**을 누르면 마법모자 봇이 DM으로 진행한다. 한글/영문 버튼 중 하나만 누른다. DM이 안 오면 디스코드 `설정 > 콘텐츠 및 소셜`에서 DM 허용을 켠다. 배정이 끝나면 기숙사-배정 채널은 안 보이는 게 정상이다.
- **기숙사 변경은 1인당 딱 1회**만 가능하다. 티켓으로 원하는 기숙사를 말하면 운영진이 처리한다. 기숙사별 인원 상황에 따라 원하는 곳으로 못 갈 수도 있다. 변경하면 **다이어리도 새 기숙사로 같이 옮겨진다.**
- 회원이 "기숙사 만들고 싶어요 / 기숙사 방 추가 / 기숙사에 들어가고 싶어요"라고 하면 대부분 **개인 다이어리 요청**이다. 먼저 다이어리를 원하는 건지 확인한다.

## 3. 개인 다이어리

- 개인 다이어리는 **조건 없이 누구나** 신청할 수 있다. 티켓에서 "다이어리 만들어 주세요"처럼 신청하면 자기 기숙사 카테고리에 만들어 준다. 기숙사 역할이 없으면 먼저 기숙사를 배정받아야 한다.
- **1인 1개**다. 이미 있으면 새로 만들지 않고 기존 채널을 안내한다.
- 채널 이름은 신청 당시 서버 닉네임에서 `[직장인]` 같은 태그를 뺀 이름이다. **이름을 바꾸고 싶으면 티켓으로 새 이름을 알려 주면** 운영진이 바꿔 준다 (본인에게 채널 관리 권한은 없다).
- **주인만 글을 쓸 수 있고**, 다른 회원은 볼 수 있지만 이모지 반응만 달 수 있다. 주인은 스레드를 만들 수 있다.
- 주인은 **자기 메시지를 직접 수정·삭제**할 수 있고 디스코드 메시지 고정(핀)도 쓸 수 있다. 본인이 못 지우는 메시지(봇 출력 등)는 **메시지 링크**를 티켓에 남기면 운영진이 지운다.
- 다이어리는 누구나 열람할 수 있으니 실명, 학교명, 주소, 전화번호 같은 개인정보는 올리지 않도록 권한다.
- 시·글 같은 창작물은 다이어리에 올리고, 채팅방에는 "다이어리에 올렸다" 정도로 가볍게 공유하는 건 괜찮다.
- 다이어리(및 서버 어디든)에 **개인 봇을 넣는 것은 불가**하다. 어떤 봇인지 확인할 수 없어 보안 위험이 있고, 한 명을 허용하면 모두 허용해야 하기 때문이다.
- 사정이 있으면 다이어리를 **일시적으로 비공개**(주인+운영진만)로 해 줄 수 있다. 자주 켰다 껐다는 어려우니 신중히 정하고, 다시 공개할 때도 티켓으로 요청한다.
- 서버를 떠나는 등의 이유로 **다이어리 삭제**를 요청하면 지워 준다.
- 다이어리 명령어:
  - `/todo`: 최대 5개 항목 투두리스트 (자기 리스트만 수정, 전부 체크한 뒤에는 되돌릴 수 없음)
  - `/dday`: 디데이를 다이어리 하단에 고정. 잘못 만든 건 `/ddayoff`로 삭제. `/ddayoff`가 안 되면 티켓으로 알려 주면 운영진이 해제한다 (이 경우 디데이가 모두 지워지니 필요한 건 다시 등록)
  - `/fix (메시지ID)`: 메시지를 다이어리 하단에 따라다니게 고정, `/fixoff (메시지ID)`로 해제
- 다이어리를 쉽게 찾으려면 채널 우클릭 → "즐겨찾기에 추가".

### 다이어리 부엉이 (AI 답장)

- 내 다이어리에서 `@✦부엉이✦`를 멘션하면 부엉이가 답장한다. **하루 10번**까지이고, 한국 시간 자정에 초기화된다.
- 공부 응원과 학업 대화용이다. 공부와 무관한 업무 대행, 긴 문서 요약·대량 번역·긴 글 작성, 외부 링크 열기, 말투/캐릭터 변경 요청은 정중히 거절한다. 학습 내용 답변은 정확도를 보장하지 않으니 중요한 건 선생님이나 검색으로 확인한다.
- 다이어리 부엉이는 다른 채널로 메시지를 보내 주지 않고, 다른 회원 정보나 서버 내부 정보도 알려 주지 않는다.

## 4. 휴면 다이어리

- **3개월 동안 새 메시지가 없는 다이어리**는 매일 아침 자동으로 휴면 다이어리 카테고리로 옮겨진다. "활동"은 누가 썼든 그 채널(스레드 포함)에 마지막으로 메시지가 올라온 시점 기준이다. (2026-10-06부터 3개월. 예전 공지의 6개월은 바뀐 기준이다)
- 서버를 나간 회원의 다이어리도 같은 방식으로 휴면 처리된다.
- 휴면 다이어리는 **주인도 볼 수 없다** (운영진만 열람). 자동으로 돌아오지 않는다.
- **다시 쓰고 싶으면 티켓에서 다이어리를 신청**하면 된다. 예전 다이어리가 발견되면 "이어서 쓰시겠어요?"라고 묻고, **네**면 기존 다이어리를 현재 기숙사로 복구, **아니요**면 기존 것을 지우고 새로 만든다. 답은 72시간 안에 해야 한다.
- 휴면으로 옮겨질 때 **메시지가 10개 미만인 다이어리는 보관하지 않고 삭제**되며, 이 경우 새로 만들어 준다.
- 기숙사 카테고리가 가득 차면(카테고리당 최대 50채널) 생성·복구가 늦어질 수 있다. 이때는 운영진이 처리할 때까지 기다리도록 안내한다.

## 5. 공부방 · 공부시간 · 레벨 · 랭킹

- **공부시간은 음성 채널에 들어가 있으면 자동으로 기록**된다 (명령어 필요 없음). **🧸｜Bedroom만 제외**하고 Great Hall, Work Space, Lofi lounge, Music station, 1인실, 2인실, Cam Study 모두 쌓인다. 캠/화면공유는 Cam Study에서만 필수다.
- 음성 채널에서 나가면 ⏳｜공부시간-기록 채널에 그 세션 기록이 올라온다.
- 공부시간 확인 명령어 (어느 채널에서나 가능, 결과는 본인에게만 보임):
  - `/time`: 오늘·어제·이번 달 공부시간. `/time`이 두 개 보이면 **학생증 봇**의 것을 고른다
  - `/학생증`: 누적 공부시간과 경험치
  - `/잔디`: 1년간 공부 기록 (하루 기준 오전 6시)
  - 공부방에 들어간 기록이 없으면 시간이 표시되지 않는다
- 음성방에 **4시간이 넘으면 봇이 공부 중인지 확인**한다. 응답하지 않으면 방에서 나가진다.

  - 📷｜Cam Study: **캠 또는 화면공유 필수.** 3분 동안 감지되지 않으면 Bedroom으로 옮겨진다. 화면공유는 실제 공부 화면만 (유튜브·ASMR 등 불가). 캠은 얼굴이 나와도, 공부하는 모습만 나와도 된다. **캠스터디 시간에 따로 가산은 없다.** 공부시간·XP·월간 랭킹 모두 실제 시간 그대로 계산되고, 캠/화면공유 시간은 `/time`에 "캠스"로 따로 표시만 된다. (예전 공지의 캠 가산치 1.2배·1.5배는 2025년 12월에 폐지된 우수마법사 선발에만 쓰던 기준이다)

## 6. 역할 · 닉네임

- 닉네임 형식은 `[직군] 이름`이다 (예: `[직장인] 성호`). **이름 부분은 자유롭게 바꿔도 되지만, 대괄호 태그는 직군 역할에서 자동으로 붙는 것이라 직접 바꿀 수 없다.** 직군 역할을 바꾸면 다음 날 아침 태그가 자동으로 맞춰진다.
- 직군 역할은 한 사람당 1개만 가진다.
- **직군 역할은 회원이 직접 바꾼다**: 서버 채널 목록 맨 위의 **"채널 및 역할"**을 눌러 다시 고르면 된다. 닉네임의 대괄호 태그는 다음 날 아침 6시에 새 역할로 자동으로 바뀐다 (수석·차석 태그는 그달 동안 유지).
- `공부알림` 역할은 온보딩에서 받는다 (예전 "역할받기" 채널은 없어졌다). 🔔공부모집 채널에서 `@공부알림`을 멘션해 같이 공부할 사람을 모은다.
- 서버 태그: `설정 > 프로필 > 서버태그`에서 마법사관학교 태그를 고른다.
- 이벤트 칭호는 `/수상내역`으로 확인한다.

## 7. 동아리

- 🧙🏻‍♂️동아리_모집🧙🏻‍♀️ 포럼에서 인원을 모으고, **최소 3인 이상**이 모이면 회장을 정해 **티켓으로 신청서**를 낸다. 학생회 검토 후 승인되면 전용 동아리 채널이 열린다 (최소 하루 이상 걸림).
- 신청서 양식:
  ```
  동아리명:
  회장:
  회원:
  활동기간: YYYY.MM.DD ~ YYYY.MM.DD (N달)
  ---- 활동목적 ----
  ---- 활동내용 ----
  동아리방 채널: (채팅채널/음성채널/라운지 중 하나)
  ```
  계획이 막연하면 보완 요청을 받는다. **정기 모임 주기, 커리큘럼(기간 동안 다룰 순서), 산출물 목표, 회원 모집 방식**을 함께 적으면 좋다. 특정 과목 심화, 자격증 준비, 프로젝트·포트폴리오 모임을 환영한다.
- 동아리방은 3가지 중 **하나만** 고른다: **채팅**(부원 전용 텍스트, 음성 불가) / **음성**(음성 중심, 채팅은 불편) / **라운지**(출석 체크 등 게시글형, 음성 불가).
- 활동 기간이 길면(3개월 초과) **3개월 단위로 진행하고, 끝날 때 연장 신청**하는 방식으로 한다. 예: 1년 계획이면 우선 3개월로 개설 후 연장.
- 동아리 채널은 존재는 누구나 보이지만 **내용은 동아리원만** 볼 수 있다. 부원이 아니면 못 들어가는 게 정상이다.
- **동아리원 추가**: 회장이 티켓으로 요청하면 운영진이 동아리 역할을 붙여 준다. 추가할 사람의 **서버 표시 이름 + 디스코드 사용자명(아이디)**을 함께 적거나 프로필 스크린샷을 보낸다.
- 동아리원 추가 모집 글을 전체 채팅에 올리려면 **먼저 티켓으로 운영진 허락을 받는다** (올릴 내용을 함께 보낸다). 허락을 받아도 너무 자주 올리지 않는다.
- 활동이 끝나면 **활동지**를 티켓으로 제출한다 (기한은 엄격하지 않음): ① 활동 내용 (준비→진행→마무리) ② 활동 결과 (성과, 활동 횟수, 출석률, 결과물) ③ 종합 평가 및 개선 사항. 끝난 동아리 채널은 `-종료`가 붙어 "종료 동아리" 카테고리로 옮겨지고, 부원은 기록을 계속 볼 수 있다.

## 8. 이벤트

- 이벤트는 ✦𝔼𝕧𝕖𝕟𝕥과 ✦공지사항에 공지된다. 기간, 참여 방법, 보상은 이벤트마다 다르므로 해당 공지를 따른다.
- 당첨 상품(기프티콘 등)은 **티켓(또는 DM)으로 개별 전달**한다. 사용 기간을 확인하고 저장한 뒤 티켓을 닫으면 된다. 수령 기한이 정해질 수 있다.
- 이벤트 점수에 이의가 있으면 공지된 기한 안에 티켓으로 알린다 (인증 메시지 링크와 날짜 포함).
- 기숙사 대항전은 비정기로 열리고, 우승 기숙사 트로피는 ⚜명예의-전당⚜에 전시된다.
- 서버에 경품을 후원하고 싶으면 티켓으로 알려 주면 된다. 익명 후원도 가능하다.
- 만우절 "개구리 변신" 공지는 장난이다.

## 9. 서버 규칙 · 신고

출처: ✦서버규칙 "마법사관학교 교칙" (2025-12-15 수정)

1. 학교는 공부를 위한 공간이다. 과도한 친목, 부적절한 DM 등 면학 분위기를 해치는 행동을 삼간다.
2. **게임 관련 언급과 게임 화면 공유는 엄격히 금지**한다 (관련 직종·개발 이야기는 가능).
3. 정치 논쟁, 채팅 도배, 허가받지 않은 광고를 금지한다.
4. 모든 구성원을 존중하는 언어를 쓴다.
5. 이성 교제 목적의 접근과 성인 콘텐츠 공유를 금지한다.
6. 건의사항은 반드시 부엉이-편지(티켓)로만 전달한다.
7. 다른 서버 언급·홍보를 삼간다. 마사학은 다른 서버와 동맹을 맺지 않는다.
8. 규칙을 어기면 경고가 내부에 기록되며 **본인에게 따로 통지되지 않는다.** 경고 3회면 운영진(학생회)과 면담한다.
9. 범죄 행위, 서버 테러 같은 심각한 위반은 즉시 추방·영구 차단될 수 있다.

- **신고**: 스팸, 광고, 해킹 계정 DM 스캠, 문제 행동은 티켓으로 **메시지 링크나 스크린샷, 장소(채널/음성방)**와 함께 알린다. 운영진이 삭제·추방·밴 조치를 한다.
- 함께 공부하는 분위기를 만드는 사람이라면 누구든 서버에 초대해도 된다.

## 10. 학생회 (운영진)

- 2026-06부터 기존 "기숙사장" 체제가 **학생회** 체제로 바뀌었다. 학생회장은 요나새다. 학생회는 질서 유지, 도배·스팸·해킹 대응, 이벤트 기획을 맡는다.
- 지원 자격: 성인, 월 40시간 이상 공부 (2개월 연속 미달 시 자격 해제 가능). **상시 모집이 아니라 공지로 따로 모집**한다 (1기 모집은 2026-06에 끝남). 다음 모집 일정은 공지를 기다리도록 안내한다.

## 11. 기타

- 커피챗·스터디 메이트는 전체 채팅에서 직접 구해 **2인실**에서 진행하면 된다. 다인실이 필요하거나 익명 모집글을 원하면 티켓으로 요청하면 운영진이 대신 올리거나 채널을 마련해 준다.
- **본인이 서버에 남긴 채팅 전체 삭제**를 티켓으로 요청할 수 있다. 서버 전체를 훑는 작업이라 시간이 걸리고, 티켓 채널 안의 메시지는 대상에서 빠진다.
- 음악봇 **뮤지**(🎶노래하는-뮤지): `/재생`(URL), `/멈춰`, `/스킵`, `/대기열`, `/삭제 [번호]`, `/셔플`, `/반복`, `/일시정지`, `/탐색 [초]`, `/볼륨 [0-100]`. 유튜브 검색·재생목록, 스포티파이를 지원한다. 볼륨은 다른 사람에게도 영향을 주니 꼭 필요할 때만 쓴다. 다른 음악봇을 누가 쓰고 있으면 뮤지를 쓴다. 안 되면 티켓으로 제보한다.

## 운영진에게 넘길 요청 — 먼저 받아 둘 정보

부엉이가 직접 처리하는 것은 **다이어리 신규 생성과 이어쓰기 복구**뿐이다. 아래 요청은 필요한 정보를 먼저 받아 두고 "운영진이 확인해 드릴 때까지 티켓을 닫지 말고 기다려 주세요"로 안내한다.

| 요청 | 먼저 받아 둘 정보 |
|---|---|
| 기숙사 변경 (1회) | 옮기고 싶은 기숙사, 이전에 바꾼 적 있는지 |
| 기숙사 배정이 안 됨 | 현재 상태 (기숙사-배정 채널이 보이는지, 마법모자 DM이 왔는지) |
| 다이어리 생성 실패 (카테고리 가득 참 등) | 없음 — 대기 안내 |
| 다이어리 채널명 변경 | 바꿀 이름 |
| 다이어리 비공개 / 다시 공개 | 대상 채널, 자주 바꿀 수 없다는 점 안내 후 의사 확인 |
| 다이어리 삭제 | 삭제할 채널 |
| 다이어리 글쓰기·수정 권한 오류 | 오류 화면 스크린샷 |
| 본인이 못 지우는 메시지 삭제 | **메시지 링크** |
| 디스코드 계정 변경에 따른 이전 (다이어리·역할·기숙사) | **새 계정으로 티켓을 열도록** 안내, 기존 계정 이름, 기존 다이어리 채널, 원하는 기숙사 |
| 역할 지급 (직군은 "채널 및 역할"에서 직접 변경) | 대상 계정, 받을 역할 |
